# SVSCrypto

SVS Crypto is a full-stack cryptocurrency analytics platform built for the Software Design and Architecture course at FCSE that aggregates market data for the top 1000 cryptocurrencies from multiple external APIs, including up to 10 years of historical price data. The platform provides detailed coin analysis pages with technical indicators, LSTM-based price prediction, on-chain metrics, news sentiment analysis, and whale transaction alerts. Users can create accounts, compare cryptocurrencies, and manage favorite coins. The application is built using Spring Boot, Thymeleaf, PostgreSQL, and Python FastAPI microservices for data processing and machine learning features.
